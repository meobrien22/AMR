AZEROTH MORNING RADIO — ANIMATED TEXT PACK

Six standalone, silent, transparent HTML overlays. No external fonts, images, account, or internet connection required.
Designed for a 1920 x 1080 canvas. Each animation enters, holds, then exits after six seconds.
These are Browser Source overlays, not video files. The surrounding canvas is transparent; the designed title plate is intentionally visible.

OBS SETUP
1. Unzip this entire folder.
2. Add a Browser Source and enable Local file.
3. Select one of the six numbered HTML files (not the portfolio homepage).
4. Set Width to 1920 and Height to 1080. Position this source above the camera/game in Sources.
5. Enable Refresh browser source when scene becomes active to replay on scene activation.
6. Use Refresh cache of current page in the source properties to trigger a replay whenever needed.
The source goes transparent when the six-second animation finishes. Switch away and back to the scene to trigger it again.
If your computer prefers reduced motion, the overlays use a simple fade instead of moving text.

Official OBS Browser Source documentation:
https://obsproject.com/kb/browser-source
