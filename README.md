# Azeroth Morning Radio — Multimedia Portfolio

A portfolio created for Jibbs & Kash, featuring 80 podcast backgrounds, 72 additional artworks, two goblin host dance films, cute and classic sticker collections, and six animated text overlays.

Open `index.html` to explore. All media and downloads are included. GitHub Pages publishes this static site from the root of the `main` branch.

The background collection includes ten show sections with eight designs for each. Sticker downloads contain transparent PNGs. Animated text downloads contain standalone HTML overlays and an OBS setup guide.

Warcraft-inspired fan concepts. Research references and artwork dimensions are included in the collection.
